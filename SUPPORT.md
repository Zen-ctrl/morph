# MORPH support

MORPH is currently a private engineering project, not a supported commercial service.
There is no response-time or compatibility SLA.

Before asking for help:

1. Read the quick start in `README.md`.
2. Run `pnpm morph doctor`.
3. Check `docs/README.md`, especially the API, CLI, semantics, and format guides.
4. Search existing issues.

Use the GitHub question form for installation, SDK, CLI, workbench, or interpretation
questions. Use the bug form for reproducible failures. Include the commit, Node.js and pnpm
versions, operating system, command, and a synthetic reproduction.

Do not attach private datasets, credentials, provider responses, or sensitive artifact
contents. Security vulnerabilities must follow `SECURITY.md`.

The project does not currently provide:

- published npm packages;
- a live model provider integration;
- model-quality guarantees;
- provider billing-token accounting;
- public API uptime or hosted compilation;
- support for private application data through the project website.
